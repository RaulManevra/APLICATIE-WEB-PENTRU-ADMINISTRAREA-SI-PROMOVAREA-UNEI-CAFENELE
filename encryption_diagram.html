sequenceDiagram
    participant Client as 🌐 Browser (Client)
    participant Server as 🔒 Server (PHP/OpenSSL)
    participant DB as 💾 Database

    Note over Client, Server: 1. Handshake & Key Exchange
    Client->>Server: Request RSA Public Key
    Server-->>Client: Send RSA Public Key (PEM)

    Note over Client: 2. Data Preparation
    Client->>Client: Generate Random AES-GCM Key (256-bit)
    Client->>Client: Generate Random IV (12 bytes)
    Client->>Client: Collect Sensitive Data (Card Info)

    Note over Client: 3. Encryption (Hybrid)
    Client->>Client: Encrypt Data with AES Key + IV -> [Ciphertext]
    Client->>Client: Encrypt AES Key with RSA Public Key -> [Encrypted Key]

    Note over Client, Server: 4. Secure Transmission
    Client->>Server: POST Order Data
{Ciphertext, IV, Encrypted Key, AuthTag}

    Note over Server: 5. Decryption
    Server->>Server: Decrypt [Encrypted Key] using Server Private Key -> AES Key
    Server->>Server: Decrypt [Ciphertext] using AES Key + IV -> Sensitive Data

    Note over Server, DB: 6. Processing
    Server->>DB: Check Stock / Save Order (Tokenized)
    Server-->>Client: Success Response
