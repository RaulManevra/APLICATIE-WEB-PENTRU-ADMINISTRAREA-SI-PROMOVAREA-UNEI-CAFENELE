Ripple Effect Visualizer

Click the button below to trigger the Ripple Effect.
We will freeze the calculation to show you the exact math behind the wave.

1. Geometry Capture
Button Rect: W=0, H=0 | Left=0, Top=0
Mouse (Global): ClientX=0, ClientY=0
2. Math Logic
Diameter = MAX(W, H) = 0px
Radius = Diameter / 2 = 0px
Relative X = ClientX - RectBufferLeft = 0 - 0 = 0px
Relative Y = ClientY - RectBufferTop = 0 - 0 = 0px
3. Centering the Circle
To center the circle at the click point, we shift it up/left by Radius:
Circle.Left = RelativeX - Radius = 0px
Circle.Top = RelativeY - Radius = 0px
